# 잠재 사용자 리서치

> 출처: [작가 인터뷰](작가%20인터뷰.md) · [시장 조사](시장%20조사.md) ·
> [기존 웹소설 플랫폼 유저 반응](기존%20웹소설%20플랫폼%20유저%20반응.md) ·
> [웹소설 표지가 웹소설 구매에 끼치는 영향](웹소설%20표지가%20웹소설%20구매에%20끼치는%20영향.md)

슥에는 사용자가 둘이다. **영상을 만드는 작가**와 **영상을 보는 독자**.
둘의 이해가 한 곳에서 충돌하는데, 그 지점이 이 제품의 최대 리스크다.

---

## 1. 두 사용자 개요

| | 작가 | 독자 |
|---|---|---|
| 하는 일 | 영상을 만든다 | 영상을 본다 |
| 원하는 것 | 내 작품이 알려지는 것 | 내 상상이 지켜지는 것 |
| 현재 행동 | X · 포스타입에서 직접 홍보 | 표지로 고르고, 유료 결제 |
| 슥에 대한 태도 | 홍보 무기 | 상상을 침범할 수 있는 물건 |
| 조사 상태 | 심층 인터뷰 (표본 부족) | **직접 조사 없음** — 2차 관찰만 |

---

## 2. 작가 — 만드는 쪽

### 2.1 페르소나

**"연재 3개월차, 조회수가 안 오른다"**

| 항목 | 내용 |
|---|---|
| 상황 | 연재 중 · 편당 수익 500만 원 미만 (작가의 70.8%) |
| 하고 있는 일 | X · 포스타입에서 직접 홍보 |
| AI 사용 경험 | 글쓰기 보조는 들어봤다. **이미지·영상은 만들어본 적 없다** |
| 영상화 인식 | "꿈같은 얘기. 일단 인기가 많아야 하고…" |
| 태도 | 거부가 아니라 **무관심** |

### 2.2 Job-to-be-done

| 구분 | 진술 | 판정 |
|---|---|---|
| 겉으로 보이는 것 | "내 소설을 영상으로 만들고 싶다" | 폐기 |
| 실제 | **"내 소설을 더 많은 사람이 읽게 하고 싶다"** | 채택 |

영상은 목적이 아니라 **홍보 수단**이다. 이 순서를 뒤집으면 제품이 틀어진다.

### 2.3 페인 — 닭-달걀

```
인기가 있어야 → 영상화된다      작가는 이 고리를 스스로 못 끊는다
영상화돼야   → 인기가 생긴다
```

| 고리를 만드는 것 | 슥의 개입 |
|---|---|
| 영상화 비용이 높다 | 원고 붙여넣기 한 번으로 낮춘다 |
| 그래서 상위 1%만 통과한다 | 인기와 무관하게 먼저 만든다 |
| 통과 못 하면 알려질 방법이 없다 | 그 영상으로 인기를 만든다 |

### 2.4 설계 규칙

| 하지 말 것 | 할 것 | 이유 |
|---|---|---|
| "AI 스튜디오"로 소개 | 결과물부터 보여주기 | 타깃이 AI 비사용자 |
| 프롬프트 입력 요구 | 원고 붙여넣기 하나 | "어렵고 필요한가 싶고" |
| 풀 에피소드부터 제안 | **30초 트레일러**로 진입 | 내일 올릴 것이어야 함 |
| "감독이 되세요" | "지금 하는 홍보를 영상으로 무장" | 새 일거리가 아니라 있는 일을 덜어줌 |

## 3. 독자 — 보는 쪽

### 3.1 이미 지갑을 연다

| 지표 | 값 |
|---|---:|
| 유료 결제 경험 | 79.0% |
| 1회 평균 결제액 | 8,032원 |
| 이용자 수 | 587만 명 |

수요 부족 문제가 아니다.

### 3.2 검증된 선호

| 기능 | 왜 통하는가 |
|---|---|
| 기다리면 무료 | 가장 성공한 과금 모델 |
| 별점 · 댓글 | 8.5 이상이면 볼 만하다는 암묵적 기준 |
| TTS | 이동 중 · 집안일 중 소비 패턴에 부합 |
| 다크모드 | 야간 독서 비중이 높아 사실상 필수 |
| 표지 확대 | 표지를 능동적으로 감상하고 싶어함 |

## 4. 최대 리스크 — 두 사용자가 여기서 충돌한다

독자 조사에서 나온 가장 강한 부정 신호는 **가상캐스팅에 대한 거부감**이었다.

| 독자 발언 | 읽히는 것 |
|---|---|
| "원작 캐릭터랑 이미지가 안 맞음" | 이미 머릿속에 캐스팅이 끝나 있다 |
| "몰입이 깨진다" | 외부 이미지가 독서 경험을 침범한다 |
| "코스프레 같고 거부감 듦" | 어설퍼서가 아니라 재현 자체를 거부 |
| "2D·3D는 아예 다른 세상인 느낌" | 매체가 바뀌면 다른 작품으로 인식 |

**이것은 슥의 핵심 가정을 정면으로 때린다.**
작가에게는 홍보 무기인 영상이, 독자에게는 상상을 침범하는 물건일 수 있다.

### 4.1 왜 거부하는가

독자는 읽으면서 **자기 머릿속에 이미 캐스팅을 끝냈다.**
외부에서 온 얼굴은 그 캐스팅을 덮어쓴다.

| | |
|---|---|
| 품질 문제라면 | 더 잘 만들면 해결된다 |
| **소유권 문제라면** | **더 잘 만들수록 더 강하게 덮어쓴다** |

후자로 보인다. 개선으로 풀리지 않는다는 뜻이다.

### 4.2 표지는 되는데 영상은 안 되는 이유

| | 표지 | 영상 |
|---|---|---|
| 만나는 시점 | 읽기 **전** | 읽는 중 · 읽은 **뒤** |
| 상상에 대한 작용 | 형성 | 덮어쓰기 |
| 독자 반응 | 구매 트리거 | 거부감 |

**시점이 전부를 가른다.** 여기서 대응 방향이 나온다.

### 4.3 대응 가설 — 전부 미검증

| # | 가설 | 근거 | 검증 방법 |
|---|---|---|---|
| 1 | **읽기 전에 보면 괜찮다** | 침범할 상상이 아직 없다 (§4.2) | 읽은 독자 / 안 읽은 독자 반응 비교 |
| 2 | **양식화된 매체가 안전하다** | "2D·3D는 아예 다른 세상" → 거리가 완충 | 애니 · 웹툰 · 실사 A/B |
| 3 | **작가가 만들면 정당성이 생긴다** | 플랫폼 광고가 아니라 원작자의 선택 | "작가가 만든" 표기 유무 비교 |
| 4 | **얼굴을 덜 보여주면 덜 부딪힌다** | 분위기 · 상황 중심 연출 | 얼굴 노출 비중별 반응 |

> 전시 파이프라인에서 얼굴 일관성에 공을 들인 것도 같은 문제의 다른 얼굴이다.
> 일관성이 깨지면 거부감이 더 커진다.

## 5. 종합

```
작가                          독자
"알려지고 싶다"                "내 상상을 지키고 싶다"
        └──────  슥  ──────────┘
     이 둘을 동시에 만족시켜야 한다
```

| # | 설계 결론 | 근거 |
|---|---|---|
| 1 | 진입은 **읽기 전** 지점 — 트레일러 · PV | §4.2, 가설 1 |
| 2 | 매체는 **양식화된 쪽**을 기본으로. 실사는 신중히 | 가설 2 |
| 3 | **"작가가 직접 만든"** 맥락을 항상 붙인다 | 가설 3 |
| 4 | 독자용 뷰어에서 영상을 **강제하지 않는다** — 토글 | §4.1 |
