# 차세대 웹드라마 플랫폼 : 슥- 하고 발견하는 재미

본 서비스는 단순한 콘텐츠 소비를 넘어, 작가의 창작 효율을 극대화하고 독자의 2차 창작을 유도하며, **웹소설 IP가 AI 웹드라마로 자동 변환·유통되는 선순환 생태계** 구축을 목표로 합니다.

---

## 0. 현재 포지셔닝

> 이 절은 [작가 인터뷰](research/작가%20인터뷰.md) · [시장 조사](research/시장%20조사.md) ·
> [잠재 사용자 리서치](research/잠재%20사용자%20리서치.md) 이후 정리된 **현재 방향**이다.
> 1장 이하는 초기 올인원 플랫폼 비전으로, 장기 그림으로 남긴다.

### 0.1 한 문장

> **슥은 웹소설 작가가 자기 작품의 홍보 영상을 직접 만드는 서비스다.**

"AI 영상 제작 툴"이 아니다. 작가가 **이미 하고 있는 홍보 노동**을 영상으로 무장시킨다.

### 0.2 무엇이 바뀌었나

| | 이전 | 현재 |
|---|---|---|
| 정의 | 올인원 웹소설·웹드라마 플랫폼 | **웹드라마 제작 서비스** |
| 타깃 | AI를 쓰고 싶은 창작자 | **AI를 안 써본 작가** |
| 소구 | "작가가 감독이 되는 AI 스튜디오" | **"이미 하는 홍보를 영상으로 무장"** |
| 진입점 | 풀 에피소드 | **X에 올릴 30초 트레일러** |
| AI 노출 | 전면 | **숨김 — 결과물만 보여준다** |

### 0.3 왜 이 방향인가

**① 작가의 진짜 과제는 "감독 되기"가 아니라 "알려지기"다.**
인터뷰에서 작가는 이미 X·포스타입에서 홍보 중이었다. 새 욕구를 만들 필요가 없다.

**② 닭-달걀 고리를 끊는 것이 제품의 본질이다.**

```
인기가 있어야 → 영상화된다       슥은 순서를 뒤집는다.
영상화돼야   → 인기가 생긴다       인기 없어도 먼저 영상화 → 그걸로 인기를 만든다
```

**③ 숫자가 이 자리를 가리킨다.**

| | |
|---|---|
| 웹소설 시장 | 1조 3,500억 원 (2024) |
| 그런데 작가의 70.8% | 편당 500만 원 미만 |
| 영상화되는 작가 | 사실상 상위 1% |
| 숏폼 드라마 시장 | 17조 → 38조 (2025 → 2030 전망) |
| 한국 결제 전환율 | 세계 4위 |

원작도 남고 수요도 있는데 **제작비가 다리를 막고 있다.** 슥이 그 다리다.

### 0.4 가장 큰 리스크

독자는 **가상캐스팅에 강한 거부감**을 보인다 — *"몰입이 깨진다"*, *"코스프레 같다"*.
작가에겐 홍보 무기인 영상이 독자에겐 상상을 침범하는 물건일 수 있다.

대응 방향 (전부 **미검증**):
읽기 전 지점에서 만나기 · 양식화된 매체(애니·웹툰 풍) 우선 ·
"작가가 직접 만든" 맥락 명시 · 독자 뷰어에서는 영상을 토글로 둔다

> 상세는 [잠재 사용자 리서치 §4](research/잠재%20사용자%20리서치.md) 참고.

### 0.5 검증 현황

| | 상태 |
|---|---|
| 작가 페인 (닭-달걀) | 인터뷰로 확인, 표본 부족 |
| 시장 규모·분배 | 공식 통계로 확인 |
| 독자 거부감 | 커뮤니티 2차 관찰만. **직접 조사 미실시** |
| 대응 가설 4종 | **검증 0** |
| 지불 의사 | **미확인** |

## 1. 서비스 개요

### 1.1 서비스 정의
AI 기반 창작 지원, 몰입형 콘텐츠 소비, 커뮤니티, 그리고 **웹소설 → AI 애니메이션 웹드라마 자동 변환 및 유통**을 통합한 **올인원(All-in-one) 웹소설·웹드라마 플랫폼**입니다.

### 1.2 서비스 목적
| 대상 | 목적 |
| :--- | :--- |
| **작가** | AI 보조로 창작 효율 증대, IP 영상화의 진입 장벽 제거 |
| **독자·시청자** | 읽던 소설을 애니메이션 드라마로 감상하는 확장된 몰입 경험 |
| **플랫폼** | 웹소설 IP의 2차 가공을 통한 생태계 확장 및 수익 다각화 |

### 1.3 핵심 비즈니스 로직

> **Creation(작가) → Drama(IP 영상화) → Consumption(독자/시청자) → Engagement(커뮤니티) → New User/Retention(확산)**

## 3. 상세 기능 (Key Features)

### 3.1 작가 기능 (Creation)

| 기능 | 역할 |
| :--- | :--- |
| **Smart Editor** | 텍스트 편집 및 자동 저장, AI 문장 자동 완성 및 문체 유지 |
| **World Building Manager** | 인물·사건·배경 설정을 구조화 관리. AI가 설정 오류를 체크해 개연성 유지 |
| **AI Visualizer** | 소설 속 묘사 기반으로 삽화 및 캐릭터 시트 자동 생성 |
| **AI Cover Generator** | 제목과 장르 키워드만으로 표지 제작 |

### 3.2 웹드라마 기능 (Drama)

#### Creator Studio — 제작 플랫폼 (작가 전용)

웹소설 작가가 자신의 IP를 AI 애니메이션 웹드라마로 제작하는 도구입니다.

**제작 플로우**
```
웹소설 텍스트 업로드
        ↓
  AI 스크립트 자동 생성
  (장면 분할 / 대사 추출 / 감정 분류)
        ↓
  스크립트 검토·편집 (작가 개입)
        ↓
  캐릭터 외형 설정 (AI 제안 → 작가 수정)
        ↓
  장면별 배경·연출 편집
        ↓
  에피소드 미리보기 → Viewer Platform 게시
```

| 화면 | 주요 기능 |
| :--- | :--- |
| 대시보드 | 내 작품 목록, 변환 진행 상태, 조회수·좋아요 통계 |
| 업로드 | 텍스트 파일 업로드 또는 직접 입력, 에피소드 범위 설정 |
| 스크립트 에디터 | 장면 단위 대사·지문 편집, 씬 추가/삭제/순서 변경 |
| 캐릭터 스튜디오 | 캐릭터별 외형 프리셋 선택, 표정·의상 커스터마이징 |
| 씬 에디터 | 장면별 배경 선택, 카메라 앵글, 대사 타이밍 조정 |
| 미리보기·게시 | 최종 에피소드 재생, 썸네일 설정, Viewer Platform 게시 |

#### Viewer Platform — 시청 플랫폼 (독자/시청자)

완성된 AI 웹드라마를 시청하는 스트리밍 플랫폼입니다.

| 화면 | 주요 기능 |
| :--- | :--- |
| 랜딩 | 히어로 섹션, 인기·신작 쇼케이스, 장르별 추천 |
| 탐색 | 장르 필터, 인기/최신/완결 정렬, 검색 |
| 시리즈 상세 | 작품 소개, 에피소드 목록, 원작 소설 연결 |
| 플레이어 | 영상 재생, 자동 다음화 재생, 원작 소설 구절 싱크 표시 |

**Viewer 차별화 포인트**

| 포인트 | 내용 |
| :--- | :--- |
| 원작 싱크 | 소설 구절과 드라마 장면을 싱크 표시 — 읽기와 보기의 교차 소비 |
| 에피소드 단위 | 5~15분 분량 스트리밍 |
| 시네마틱 UI | 장르 감성에 맞춘 화면 |

### 3.3 독자 기능 (Consumption)

| 기능 | 역할 |

### 3.4 커뮤니티 기능 (Engagement)

| 기능 | 역할 |
| :--- | :--- |

## 4. 사용자 흐름 (User Flow)

| 흐름 | 경로 |
| :--- | :--- |

| **Growth** | 커뮤니티 2차 창작물이 SNS로 확산 → 신규 유입 → 생태계 확장 |

## 9. 전략 요약
본 프로젝트는 **"기술이 창작을 돕고, IP가 스스로 드라마가 되며, 커뮤니티가 성장을 이끈다"**는 철학 아래, 파편화된 창작·소비 환경을 하나로 통합합니다. 작가에게는 제작비 0원의 영상화 도구를, 독자에게는 읽던 소설을 보는 경험을, 플랫폼에게는 IP 기반의 확장 가능한 생태계를 제공합니다.
