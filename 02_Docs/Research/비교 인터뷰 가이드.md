# 비교 인터뷰 가이드

> 혼자 만들 때와 여럿이 만들 때, 경험이 어떻게 달라지는가.
> 연구 질문은 [연구 질문](연구%20질문.md) 참고.

---

## 1. 이 인터뷰로만 알 수 있는 것

행동 로그는 **무엇을 했는지**를 말해준다. 왜 그랬는지는 말해주지 않는다.

| 로그가 아는 것 | 로그가 모르는 것 |
|---|---|
| 탈락한 뒤 떠났다 | 실망해서인가, 만족하고 떠난 것인가 |
| 다시 제출했다 | 오기인가, 재미인가 |
| 3분간 화면을 봤다 | 내 장면을 기다린 건가, 그냥 구경한 건가 |
| 이 문장을 썼다 | 왜 하필 그 문장이었나 |

특히 **소유감**은 행동으로 드러나지 않는다.
"저건 제가 만든 거예요" 와 "우리가 만든 거예요" 의 차이는 말로만 잡힌다.

---

## 2. 설계 — 같은 사람이 양쪽을 다 겪게 한다

### 2.1 왜 집단 간 비교가 아닌가

| 방식 | 문제 |
|---|---|
| 혼자 한 사람 A · 같이 한 사람 B 를 각각 인터뷰 | **차이가 조건 때문인지 사람 때문인지 알 수 없다.** 소수 표본에서는 개인차가 조건 효과보다 크다 |
| **같은 사람이 양쪽을 겪고 스스로 비교** | 비교의 기준선이 본인이다. 소수 표본에서도 성립한다 |

질적 연구가 잘하는 것은 **본인이 느낀 차이를 말로 꺼내는 것**이다.
그러려면 본인 안에 비교 대상이 있어야 한다.

### 2.2 두 조건

같은 장치, 같은 화면. **다른 것은 사회적 구조뿐이다.**

| 조건 | 상황 |
|---|---|
| **혼자** | 단독 라운드 — 내 문장만 들어와 투표 없이 그대로 채택 |
| **같이** | 다인 라운드 — 여럿이 제출해 투표가 열리고 하나가 뽑힘 |

Studio(작가 도구)와 Theater 를 비교하면 안 된다.
**인터페이스가 통째로 달라서** 차이가 협업 때문인지 도구 때문인지 갈리지 않는다.

### 2.3 순서 균형

먼저 겪은 쪽이 기준이 되어 뒤엣것을 물들인다.
참가자 절반은 혼자 먼저, 절반은 같이 먼저 하게 한다.

| 참가자 | 1회차 | 2회차 |
|---|---|---|
| 홀수 번째 | 혼자 | 같이 |
| 짝수 번째 | 같이 | 혼자 |

### 2.4 조건을 만드는 방법

현장에서는 어느 라운드가 걸릴지 통제할 수 없다. 두 가지 중 택한다.

| 방식 | 내용 | 장단 |
|---|---|---|
| **기회 표집** | 마침 양쪽을 다 겪은 사람을 붙잡아 인터뷰 | 자연스럽지만 표본을 고를 수 없다 |
| **지정 세션** | 한산한 시각에 혼자, 붐비는 시각에 같이 오게 조율 | 통제되지만 인위적이고 섭외가 필요 |

지정 세션이 더 정확하다. **최소 6명, 가능하면 8~10명.**

## 3. 진행

| | |
|---|---|
| 시점 | 두 번째 참여 **직후** — 기억이 살아 있을 때 |
| 소요 | 10~15분 |
| 장소 | 설치물에서 떨어진 조용한 자리 |
| 기록 | 음성 녹음 (동의 후) + 메모 |
| 진행자 | 1명. 관찰자 1명이 있으면 더 좋다 |

### 시작할 때 읽어줄 말

> 잠깐 이야기 좀 나눌 수 있을까요? 10분 정도예요.
> 맞고 틀린 답은 없고, 방금 어떠셨는지가 궁금해서요.
> 기록을 위해 녹음해도 괜찮을까요? 이름은 남기지 않습니다.
> 중간에 그만두셔도 됩니다.

## 4. 인터뷰지

### 도입 — 긴장 풀기 (1분)

1. 여기 어떻게 오셨어요?
2. 오시기 전에 이게 뭐 하는 건지 알고 계셨어요?

### 경험 재구성 — 각 회차마다 따로 (각 3분)

*먼저 겪은 쪽부터 묻는다. 요약을 시키지 말고 그때로 데려간다.*

3. 문장을 쓰실 때, 화면 앞에서 어떻게 하셨는지 그대로 말씀해주실래요?
4. **왜 그 문장을 쓰셨어요?**
5. 쓰기 전에 뭘 보셨어요? *(앞 장면 · 남의 문장 · 아무것도 안 봄)*
6. 쓰다가 막힌 순간 있으셨어요? 언제요?
7. 시간이 정해져 있었는데, 그건 어떠셨어요?
8. 보내고 나서 뭐 하셨어요?
9. 영상이 나왔을 때 어떠셨어요?
10. 그게 **본인이 쓴 문장대로** 나왔다고 느끼셨어요?

*'같이' 회차에서는 이어서:*

11. 다른 분들 문장이 화면에 뜨는 걸 보셨죠. 그때 어떠셨어요?
12. 그거 보고 **본인 문장을 고치거나 다시 생각한 적** 있으세요?
13. 투표는 어떻게 고르셨어요?

### 탈락 경험 — 해당자만 (3분)

*가장 중요한 구간이다. 서두르지 않는다.*

14. 본인 문장이 안 뽑혔을 때, 그 순간 어떠셨어요?
15. 그러고 나서 뭐 하셨어요?
16. *(다시 참여했다면)* 또 쓰신 이유가 뭐예요?
17. *(떠났다면)* 그때 그만두신 이유가 뭐예요?
18. 뽑힌 문장으로 만들어진 영상은 어떻게 보셨어요?

### 비교 — 핵심 구간 (4분)

*여기가 이 인터뷰의 목적이다.*

19. **두 번 하셨는데, 뭐가 달랐어요?**
20. 둘 중 하나만 다시 한다면 어느 쪽이요? 왜요?
21. 완성된 이야기를 보면 어떤 느낌이 드세요?
    *(막히면)* 내 거 같아요, 아니면 다 같이 만든 거 같아요?
22. 혼자 했을 때랑 같이 했을 때, **'내가 만들었다'는 느낌**이 달랐어요?

### 마무리 (2분)

23. 친구한테 이걸 설명한다면 뭐라고 하시겠어요?
24. 이거 말고 다른 데서도 이런 걸 해보고 싶으세요?
25. 더 하고 싶은 말씀 있으세요?

## 5. 진행자 주의사항

이 인터뷰는 **만든 사람이 직접 진행한다.** 그래서 편향이 크게 들어간다.

| 하지 말 것 | 대신 |
|---|---|
| "같이 하니까 더 재밌으셨죠?" | "뭐가 달랐어요?" |
| "AI가 잘 만들어주던가요?" | "영상이 나왔을 때 어떠셨어요?" |
| "불편한 점 없으셨어요?" | "어디서 막히셨어요?" |
| 침묵을 못 견디고 말 채우기 | **3초 기다린다.** 그 뒤에 나오는 말이 진짜다 |
| 답을 평가하기 ("아 좋네요!") | "네", 끄덕임 |
| 내가 만든 걸 변호하기 | 비판이 나오면 **더 캐묻는다** |

> 칭찬이 나오면 의심하고, 비판이 나오면 반가워한다.
> 만든 사람 앞에서 사람들은 좋게 말한다.

### 파고들 신호

이런 말이 나오면 멈추고 더 묻는다.

| 관찰되는 말 | 후속 질문 |
|---|---|
| "좀 아쉬웠는데…" | "어떤 점이요?" |
| "그냥 뭐…" | "그냥이라 하시면?" |
| "내 거 같진 않았어요" | "그럼 누구 거 같았어요?" |
| "다시 하고 싶진 않아요" | "어느 순간에 그렇게 느끼셨어요?" |

## 6. 기록

| | |
|---|---|
| 참가자 번호 | P1, P2 … 이름은 받지 않는다 |
| 순서 조건 | 혼자 먼저 / 같이 먼저 |
| 탈락 경험 | 있음 / 없음 |
| 녹음 파일 | 참가자 번호로만 저장 |
| 전사 | 핵심 구간(14~22번) 우선 |

분석은 **질문별로 모아 비교**한다. 참가자별로 읽으면 개인 서사에 끌려간다.

---

## 7. 이 인터뷰로 말할 수 있는 것과 없는 것

| 말할 수 있다 | 말할 수 없다 |
|---|---|
| 경험이 **어떻게** 달랐는지 | 어느 쪽이 더 좋은지 |
| 소유감이 어떤 말로 표현되는지 | 그 느낌이 얼마나 강한지 |
| 탈락이 어떤 의미로 받아들여지는지 | 탈락이 재참여를 **줄인다**는 인과 |
| 행동 로그에서 본 패턴의 **이유 가설** | 그 가설의 검증 |

양적 근거는 [연구 질문 §6](연구%20질문.md)의 행동 로그가 맡는다.
**이 인터뷰는 그 숫자를 해석하기 위한 것이지, 숫자를 대신하는 것이 아니다.**
