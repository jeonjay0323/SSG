## 1. 표지는 구매 결정의 1차 필터

수십~수백 개의 작품이 나열되는 피드 환경에서, **표지 일러스트가 사실상 첫 번째 필터**로 작동한다.

| 작동 방식 | 내용 |
|---|---|
| 선택 기준 | 독자가 직접 밝히는 구매 기준 중 "표지가 내 취향인가"가 높은 비중 |
| 유입 경로 | 표지에 반함 → 작품 탐색 → 구매 |
| 이탈 경로 | 표지가 취향이 아니면 **내용 확인 전에 이탈** |

| 실사례 | |
|---|---|
| 상황 | 소설 《모순》을 원래 표지 때문에 구매하지 않고 있었음 |
| 전환 계기 | 제주도 독립서점 한정 북커버를 봄 |
| 결과 | "냉큼 사왔는데 너무 맘에 듦" |

> 출처: [더쿠 — 모순 표지 때문에 안 사고 있었다가](https://theqoo.net/book/3845863478)

## 2. 표지 속 인물 일러스트의 영향

### 2.1 구매 트리거

| 요인 | 내용 |
|---|---|
| 외형적 매력 | 남주·여주의 매력이 표지에서 드러날 때 구매 욕구 상승 |
| 그림체 품질 | "그림체도 예뻤고 재밌었어" — 작품 전반의 기대감을 끌어올림 |
| 장르 편차 | 로맨스 · 로맨스판타지에서 특히 강함 (솔로 또는 커플 구도) |

### 2.2 독서 몰입에 미치는 영향

웹소설은 삽화 없이 텍스트만으로 진행되는 경우가 많아,
**표지 이미지가 독자의 캐릭터 상상을 고정하는 역할**을 한다.

| 효과 | 내용 |
|---|---|
| 상상 고정 | 표지에서 얼굴·분위기를 한 번 인식하면, 독서 중 그 이미지로 장면을 시각화 |
| 감성 전달 | 세계관·분위기를 한 장으로 전달 → "내 취향인지" 즉시 판단 |
| 독립적 유입 | 일러스트레이터 개인 팬덤이 형성될 만큼 그림체 자체가 유입 요소 |

| 팬덤 사례 | |
|---|---|
| 형태 | 특정 일러스트레이터(필연, 파가라가, 숙자, 하라라 등)가 그린 표지 모음 스레드가 별도 존재 |
| 규모 | 수백 개의 반응 |

> 출처: [더쿠 — 로맨스판타지 카테고리 표지 모음 스레드](https://theqoo.net/romancefantasy/)

## 3. 표지 품질에 대한 독자의 민감도

### 3.1 기대치 형성

| 방향 | 결과 |
|---|---|
| 표지 품질 높음 | 내용 품질도 높을 것이라 기대 |
| 기대치 과열 | "표지가 너무 예뻐서 샀는데 내용에 실망" — 역효과 리스크 |
| 표지 품질 낮음 | 좋은 내용도 묻힘 |

### 3.2 표지를 크게 보고 싶다는 욕구

| 관찰 | 의미 |
|---|---|
| 리디 앱에서 표지 확대 불가에 대한 불만 글 | 독자가 표지를 **능동적으로 감상하고 싶어함** |
| 카카오페이지식 확대 기능 요구 | 표지는 소비 대상이지 썸네일이 아님 |

## 5. 유의점 — 표지와 영상은 다르게 작동할 수 있다

표지는 **읽기 전에** 만나기 때문에 상상을 *형성*한다.
영상은 **읽은 뒤에** 만나면 이미 만들어진 상상을 *덮어쓴다*.

| | 표지 | 영상 |
|---|---|---|
| 만나는 시점 | 읽기 전 | 읽는 중 · 읽은 뒤 |
| 상상에 대한 작용 | 형성 | 덮어쓰기 |
| 독자 반응 | 구매 트리거 | [거부감](기존%20웹소설%20플랫폼%20유저%20반응.md) |

이 문서의 긍정적 결론을 영상에 그대로 옮기면 안 된다.
자세한 것은 [잠재 사용자 리서치 §3](잠재%20사용자%20리서치.md).
