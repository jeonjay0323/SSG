# 작가 인터뷰

> 대상: 현역 웹소설 작가
> 방식: 비구조화 심층 인터뷰

이 서비스의 **출발점이 된 인터뷰**다. 기능 목록을 먼저 정해두고 검증한 것이 아니라,
작가가 실제로 한 말에서 방향이 뒤집혔다.

---

## 1. 그대로 옮긴 두 마디

| # | 발언 |
|---|---|
| 1 | **"AI로 글 쓰는 건 돕는다는데, 사진·영상은 생성해본 적 없어요. 어렵고 필요한가 싶고."** |
| 2 | **"제 작품 드라마화는 꿈같은 얘기. 일단 인기가 많아야 하고… 포스타입이랑 X에서 열심히 홍보 중이에요."** |

---

## 2. 이 두 마디에서 읽은 것

| 발언 | 표면적 의미 | 실제로 읽어야 할 것 |
|---|---|---|
| "어렵고 필요한가 싶고" | AI 영상을 안 써봤다 | 거부가 아니라 **무관심** — 설득 대상이 아니라 설계 대상 |
| "열심히 홍보 중이에요" | 홍보를 한다 | 이미 **시간을 쓰고 있다** — 새 욕구를 만들 필요가 없다 |
| "일단 인기가 많아야 하고" | 조건을 안다 | **체념** — 스스로 못 끊는 고리가 있다 |

### 2.1 타깃은 AI 사용자가 아니라 AI 비사용자다

| | 내용 |
|---|---|
| 하면 안 되는 것 | 제품을 "AI 영상 제작 툴"로 파는 것 |
| 해야 하는 것 | 프롬프트 0개 · 원고만 붙여넣기 · **결과물만** 보여주기 |
| 이유 | 'AI'를 전면에 세우는 순간 자기 얘기가 아니라고 판단한다 |

기술은 뒤에 숨고 결과만 앞에 선다.

### 2.2 진짜 Job-to-be-done

| 구분 | 진술 | 판정 |
|---|---|---|
| 겉 | "내 소설을 영상으로 만들고 싶다" | 폐기 |
| 속 | **"내 소설을 더 많은 사람이 읽게 하고 싶다"** | 채택 |

| 우리가 하는 말 | 작가가 듣는 말 |
|---|---|
| "당신을 감독으로 만들어드립니다" | 새 일거리가 생겼다 |
| **"지금 하는 홍보를 영상으로 무장시켜드립니다"** | 있던 일이 쉬워졌다 |

### 2.3 핵심 페인 — 닭-달걀 고리

```
인기가 있어야  →  영상화된다
영상화돼야     →  인기가 생긴다
```

| 고리를 만드는 것 | 슥의 개입 |
|---|---|
| 영상화 비용이 높다 | 원고 붙여넣기 한 번으로 낮춘다 |
| 그래서 상위 1%만 통과한다 | 인기와 무관하게 **먼저** 만든다 |
| 통과 못 하면 알려질 방법이 없다 | 그 영상으로 인기를 만든다 |

**순서를 뒤집는 것이 제품의 본질이다.**

## 3. 포지셔닝 전환

| | 문구 | 판정 | 이유 |
|---|---|---|---|
| 이전 | "작가가 감독이 되는 AI 스튜디오" | 폐기 | 어렵고 불필요하게 들림 |
| 이후 | **"이미 하는 홍보를 영상으로 무장"** | 채택 | 이미 겪는 문제에 붙음 |

| 항목 | 결정 |
|---|---|
| 진입 쐐기 | **X에 올릴 30초 트레일러** (풀 에피소드 아님) |
| 이유 | 완성된 웹드라마 한 편은 너무 먼 약속. 30초는 오늘의 홍보 노동에 바로 꽂힌다 |
| 슬로건 후보 | "쓰면, 드라마가 된다" / "이제, 소설을 봅니다" |

---

## 4. 이 인터뷰의 한계 — 반드시 채워야 할 것

이 문서는 **소수 표본의 심층 인터뷰**다. 방향을 잡는 데는 충분했지만
근거로 쓰기에는 부족하다.

| # | 아직 답을 못 얻은 질문 | 왜 필요한가 |
|---|---|---|
| 1 | 표본 확대 — 최소 5~7명 (연재 중 / 완결 / 데뷔 전) | 현재 표본으로는 일반화 불가 |
| 2 | 홍보에 실제로 **주당 몇 시간**을 쓰는가 | 절감 가치를 숫자로 말하려면 필요 |
| 3 | 채널별 체감 효과 순위 (X · 포스타입 · 커뮤니티) | 어디에 올릴 영상을 만들지 결정 |
| 4 | 트레일러가 나오면 **실제로 올릴 것인가** | 말이 아니라 행동 의향 |
| 5 | 캐릭터가 상상과 다를 때의 수용 범위 | 최대 리스크와 직결 |
| 6 | 지불 의사 — 무료면 쓰는가, 얼마부터 안 쓰는가 | 과금 모델 설계 |
| 7 | CP사 소속 작가의 **2차 저작물 권리** | 법적 진입 장벽 |
