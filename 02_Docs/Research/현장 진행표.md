# 실험 계획 · 현장 진행표

> 혼자 만들 때와 여럿이 만들 때, **창작 주체감**이 어떻게 달라지는가.
> 방법은 [§9 참고 문헌](#9-방법-출처)의 두 연구에서 가져왔다.

## 2. 설계

| | |
|---|---|
| 구조 | **참가자 내 설계** — 같은 사람이 혼자·같이를 모두 경험 |
| 조건 | 단독 라운드 / 다인 라운드 |
| 순서 | 절반씩 교대 (순서효과 방지) |
| 인원 | 최소 4명, 권장 6명 |
| 소요 | 약 100분 |

### 역할 배치

동점이면 **무작위**로 갈린다(후보 목록이 섞인다).
제출자끼리만 투표하면 승패가 운이 되므로 **투표자를 분리한다.**

| 역할 | 인원 |
|---|---|
| 제출 | **2~3명** |
| 투표 | 나머지 전원 |

> **제출자는 3명을 넘기지 말 것.** 후보는 최대 3개라 4명 이상이 보내면
> 무작위로 3명만 후보가 되고 나머지는 화면에 뜨지도 않는다.
> 그건 '투표 탈락'이 아니라 '미채택'이고, 섞이면 해석이 안 된다.

## 4. 창작 흐름 그리기 — 핵심 활동

원 연구는 **나 / AI** 두 주체로 그리게 했다.
우리는 협업이 대상이므로 **다른 사람**을 한 열 더 둔다.
**이 열의 변화가 곧 이 연구의 답이다.**

### 4.1 시트

각 단계마다 **그 일을 누가 한다고 느끼는지** 표시한다. 복수 선택 가능.

| 단계 | 나 | AI | 다른 사람 |
|---|:---:|:---:|:---:|
| **아이디에이션** — 무엇을 쓸지 떠올리기 | ○ | ○ | ○ |
| **문장 쓰기** — 떠올린 것을 문장으로 | ○ | ○ | ○ |
| **영상 만들기** — 문장이 장면이 되는 것 | ○ | ○ | ○ |
| **후보 제시** — 어떤 장면들이 나올지 | ○ | ○ | ○ |
| **선택** — 무엇이 채택될지 | ○ | ○ | ○ |
| **평가** — 잘 됐는지 판단 | ○ | ○ | ○ |

### 4.2 세 번 그린다

| 시점 | 무엇 |
|---|---|
| 체험 **전** | 예상 |
| 혼자 회차 **후** | 체감 |
| 같이 회차 **후** | 체감 |

**읽는 법**

| 비교 | 알 수 있는 것 |
|---|---|
| 예상 ↔ 체감 | **실행의 격차** — 사용법을 헷갈린 지점 |
| 혼자 ↔ 같이 | **협업이 실제로 개입한 국면** |
| '나' 열의 개수 | 창작 주체감의 대리 지표 |
| '다른 사람' 열이 늘어난 단계 | 여기서 협업이 체감된다 |

> 원 연구에서는 사용자가 **초기 단계(아이디에이션·조건설정)** 에서 AI 협업을 기대했으나
> 실제로는 **후반(제안·선택)** 에서 AI 개입을 체감했다. 우리 참가자의
> *"아이디어를 조금이라도 보태주면 좋겠다"* 와 같은 이야기다.

## 5. 척도 — 회차마다, 7점

**1 = 전혀 그렇지 않다 · 7 = 매우 그렇다.** 말로 묻지 말고 숫자만 적게 한다.

### 창작 주체감 (3문항)

| | |
|---|---|
| A1 | 이 장면은 **내가 만들었다**고 느낀다 |
| A2 | 이 장면에 **내 의도가 반영**됐다 |
| A3 | 이 장면을 두고 **"내가 만든 것"이라 말할 수 있다** |

### 만족도 (2문항)

| | |
|---|---|
| S1 | 만들어진 장면이 마음에 든다 |
| S2 | 결과물의 완성도가 높다 |

### 지속 사용 의도 (2문항)

| | |
|---|---|
| I1 | 앞으로도 계속 하고 싶다 |
| I2 | 다른 사람에게 권하고 싶다 |

### 기입표

| 참가자 | 조건 | A1 | A2 | A3 | S1 | S2 | I1 | I2 |
|---|---|:-:|:-:|:-:|:-:|:-:|:-:|:-:|
| P1 | 혼자 | | | | | | | |
| P1 | 같이 | | | | | | | |
| P2 | 같이 | | | | | | | |
| P2 | 혼자 | | | | | | | |

> **주체감과 만족도를 분리한 이유:** 선행 연구에서 만족도가 높아도
> 주체감은 낮을 수 있고("잘 나왔지만 내 것 같진 않다"),
> 권리 주장에 작용한 것은 만족도가 아니라 활용 의도였다.

### 읽어줄 말

> 10분 정도 이야기 나누게 됩니다. 맞고 틀린 답은 없어요.
> 기록을 위해 녹음해도 괜찮을까요? 이름은 남기지 않습니다.

## 8. 인터뷰 — 시간 없으면 이 순서

### 흐름 그림을 놓고 (필수)

> **여기 '다른 사람' 칸이 [늘었네요/그대로네요]. 왜 그럴까요?**
> **처음 예상과 실제가 다른 데가 있는데, 어디서 그렇게 느끼셨어요?**

### 탈락자 (필수)

> **본인 문장이 안 뽑혔을 때, 그 순간 어떠셨어요?**
> **그러고 나서 뭐 하셨어요?**
> *(다시 썼다면)* **또 쓰신 이유가 뭐예요?**
> **뽑힌 문장으로 만들어진 영상은 어떻게 보셨어요?**

### 전원 (필수)

> **두 번 하셨는데, 뭐가 달랐어요?**
> *(보기 카드)* **가장 재미있었던 건? 1순위, 2순위.**
> **완성된 이야기를 보면 어떤 느낌이 드세요?** — *내 거 같아요, 다 같이 만든 거 같아요?*
> **주체감 점수가 [혼자/같이]에서 더 높던데, 왜 그럴까요?**

### 여유 있으면

> **쓰기 전에 뭘 보셨어요?** (앞 장면 / 남의 문장 / 아무것도)
> **쓰다가 막힌 순간 있으셨어요?**
> **만들어진 영상, 어떻게 하고 싶으세요?**

### 보기 카드

| | | 분리하는 것 |
|---|---|---|
| **A** | 내가 쓴 문장이 영상이 되는 것 | AI 신기함 |
| **B** | 다른 사람 문장을 구경하는 것 | 협업 — 관찰 |
| **C** | 투표해서 하나를 고르는 것 | 협업 — 선택 |
| **D** | 이야기가 앞뒤로 이어지는 것 | 서사 |
| **E** | 완성된 이야기를 보는 것 | 결과물 |

**A가 몰리면 흥미의 원천은 AI다. B·C가 올라오면 협업이 작동한 것이다.**

## 진행자 수칙

| 하지 말 것 | 대신 |
|---|---|
| "같이 하니까 더 재밌으셨죠?" | "뭐가 달랐어요?" |
| "불편한 점 없으셨어요?" | "어디서 막히셨어요?" |
| 침묵 채우기 | **3초 기다린다** |
| "아 좋네요!" | "네", 끄덕임 |

> 칭찬이 나오면 의심하고, 비판이 나오면 반가워한다.
> **"우리가 만든 거죠"** 가 나오면 → **"우리라고 하신 게 누구예요?"**

### 원 연구와 다르게 한 것

| | 원 연구 | 이번 |
|---|---|---|
| 흐름 주체 | 나 / AI | **나 / AI / 다른 사람** |
| 비교 축 | 사용 전 ↔ 후 | 전 ↔ 후 **+ 혼자 ↔ 같이** |
| 분석 | RM ANOVA (n=93) | **기술통계 + 질적 해석** — n이 작아 검정 불가 |

**통계적 유의성은 주장할 수 없다.** 조건 간 차이의 경향과 그 이유가 이번 조사의 산출물이다.
