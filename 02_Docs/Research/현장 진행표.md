# 현장 진행표

> 세션 당일에 들고 쓰는 한 장. 전체 설계는 [비교 인터뷰 가이드](비교%20인터뷰%20가이드.md).

---

## 오늘의 목표 — 하나만

> **투표 탈락을 실제로 발생시키고, 그 직후를 관찰한다.**

재미도 어려움도 이미 확인됐다. **탈락만 한 번도 관측된 적이 없다.**

---

## 시작 전 확인

| | |
|---|---|
| 접수 창이 **40초**인가 | 15초면 다인 라운드가 안 생긴다 |
| 라이브 모드인가 | `--live` 없으면 영상이 안 만들어진다 |
| 예산 여유 | 다인 라운드 1회 = 후보 3편 ≈ $0.6 |
| 포스트잇·펜 | 척도 기입용 |
| 보기 카드 5장 | A~E |
| 녹음 준비 | |

## 역할 배치 — 탈락을 만들려면

동점이면 **먼저 낸 사람이 이긴다.** 제출자끼리만 투표하면
항상 늦은 사람이 지고, 그건 "선호로 졌다"가 아니라 "느려서 졌다"가 된다.

| 역할 | 인원 |
|---|---|
| 제출 | 2명 |
| 투표 | 2명 이상 (제출하지 않은 사람) |

**라운드마다 역할을 바꾼다.**

## 읽어줄 말

**녹음 동의**

> 잠깐 이야기 좀 나눌 수 있을까요? 10분 정도예요.
> 맞고 틀린 답은 없고, 방금 어떠셨는지가 궁금해서요.
> 기록을 위해 녹음해도 괜찮을까요? 이름은 남기지 않습니다.
> 중간에 그만두셔도 됩니다.

**규칙 설명**

> 먼저 보낸 분이 라운드를 열고, 그 뒤 40초 안에 들어온 문장들끼리 투표합니다.
> 한 문장은 40자까지예요.

## 사전 질문 (체험 전)

1. 여럿이 같이 AI로 뭔가를 만든다고 하면, 어떨 것 같으세요?
2. 평소에 뭔가 만들어서 남에게 보여주신 적 있으세요?

## 인터뷰 — 시간 없으면 이 순서로

### 반드시 (탈락자)

> **본인 문장이 안 뽑혔을 때, 그 순간 어떠셨어요?**
> **그러고 나서 뭐 하셨어요?**
> *(다시 썼다면)* **또 쓰신 이유가 뭐예요?**
> **뽑힌 문장으로 만들어진 영상은 어떻게 보셨어요?**

### 반드시 (전원)

> **두 번 하셨는데, 뭐가 달랐어요?**
> *(보기 카드)* **가장 재미있었던 건? 1순위, 2순위.**
> **완성된 이야기를 보면 어떤 느낌이 드세요?** — *내 거 같아요, 다 같이 만든 거 같아요?*
> **아까 [항목] 점수가 [혼자/같이]에서 더 높던데, 왜 그럴까요?**

### 여유 있으면

> **쓰기 전에 뭘 보셨어요?** (앞 장면 / 남의 문장 / 아무것도)
> **쓰다가 막힌 순간 있으셨어요?**
> **보내고 나서 뭐 하셨어요?**
> **처음에 어떨 것 같다고 하셨는데, 지금은 어떠세요?**
> **만들어진 영상, 어떻게 하고 싶으세요?**

## 보기 카드

| | |
|---|---|
| **A** | 내가 쓴 문장이 영상이 되는 것 |
| **B** | 다른 사람 문장을 구경하는 것 |
| **C** | 투표해서 하나를 고르는 것 |
| **D** | 이야기가 앞뒤로 이어지는 것 |
| **E** | 완성된 이야기를 보는 것 |

**A가 1순위로 몰리면 흥미의 원천은 AI다. B·C가 올라오면 협업이 작동한 것이다.**
고르지 않은 카드도 **왜 안 골랐는지** 한 번 묻는다.

## 진행자 수칙

| 하지 말 것 | 대신 |
|---|---|
| "같이 하니까 더 재밌으셨죠?" | "뭐가 달랐어요?" |
| "불편한 점 없으셨어요?" | "어디서 막히셨어요?" |
| 침묵 채우기 | **3초 기다린다** |
| "아 좋네요!" | "네", 끄덕임 |

> 칭찬이 나오면 의심하고, 비판이 나오면 반가워한다.

**"우리가 만든 거죠"** 가 나오면 → **"우리라고 하신 게 누구예요?"**
