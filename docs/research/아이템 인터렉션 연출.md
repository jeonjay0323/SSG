# Item Interaction Plan: [기억의 오브제]
> **관람객의 선택(아이템 습득)에 반응하는 실시간 인터랙티브 서사 연출**

본 섹션은 관람객이 전시된 특정 소품을 집어 드는 행위를 통해, 웹소설 속 '사건의 실마리를 쥐는 주인공'으로 완전히 동화되도록 설계되었습니다.

---

## 1. 연출 개요

### 1.1 연출 컨셉

| 항목 | 내용 |
| :--- | :--- |
| **명칭** | 운명의 선택 (The Fatal Choice) |
| **내용** | 테이블의 소품 3가지 중 하나를 집어 드는 순간, 대형 스크린 속 북부대공이 해당 아이템 전용 대사와 반응을 보인다 |
| **목적** | 수동적 관람을 넘어선 **능동적 서사 개입** 경험 |

---

## 2. 인터랙션 구조 및 시나리오

| 관람객 액션 (소품 선택) | 북부대공의 반응 (영상 연출) | 감정선 및 의도 |
| :--- | :--- | :--- |
| **[검]**을 집어 들 때 | "검술에 관심이 있는 건가? 내 직접 가르쳐 줄 수도 있는데." | 호기심, 흥미, 강인함 |
| **[말린 꽃]**을 집어 들 때 | "그 꽃의 꽃말은 '영원한 속박'이지. 너와 잘 어울리는군." | 부드러운 집착, 로맨틱함 |
| **[비밀 편지]**를 집어 들 때 | (정색하며 다가옴) "그건 읽지 않는 게 신상에 좋을 거다." | 경계, 긴장감, 소유욕 |

---

## 3. 기술 구현 계획 (Technical Specification)

비전공자/디자이너를 위한 최적의 로우코드(Low-code) 솔루션을 적용합니다.

### 3.1 하드웨어 구성

| 부품 | 역할 | 설치 위치 |
| :--- | :--- | :--- |
| **RFID 태그** | 소품 식별 | 각 소품(검·꽃·편지) 내부에 스티커형 칩 부착 |
| **RFID 리더기** | 태그 감지 | 전시대 바닥면 아래에 매립 — 보이지 않게 |
| **아두이노** | 신호 전달 | 리더기의 "들림/놓임" 신호를 PC로 전달 |

### 3.2 소프트웨어 로직

| 항목 | 내용 |
| :--- | :--- |
| **데이터 흐름** | `RFID 태그 이탈` → `아두이노 신호 발생` → `TouchDesigner 수신` → `타임라인 영상 재생` |
| **프로그램** | **TouchDesigner** — 비주얼 노드 방식이라 코딩 최소화 |

---

## 4. 디자이너를 위한 연출 포인트 (Design Tips)

| 포인트 | 내용 |
| :--- | :--- |
| **심리스 디자인** | 센서·전선이 드러나지 않도록 상판 아래 매립 — 마법처럼 느껴지게 |
| **사운드 피드백** | 드는 순간 낮은 진동음을 영상과 함께 출력해 조작감을 높인다 |
| **기다림의 미학** | 내려놓으면 대기 상태로 돌아가는 부드러운 페이드아웃 영상 |

---

## 5. 기대 효과

| 효과 | 내용 |
| :--- | :--- |
| **몰입도 극대화** | 단순 시청이 아닌 "내가 소설 속 트리거를 눌렀다"는 성취감 |
| **반복 체험 유도** | 다른 물건의 반응을 보려고 전시대 체류 시간이 늘어난다 |
| **SNS 바이럴** | "물건을 들었더니 대공이 나를 쳐다봤다" 식의 후기 생성 |
