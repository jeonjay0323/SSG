# 기존 웹소설 플랫폼 유저 반응

> 출처: 인스티즈, 디시인사이드, 더쿠, 앱스토어 리뷰, 나무위키 등

## 1. 부정 반응

### 1.1 탐색 · 추천

| 문제 | 독자 반응 |
|---|---|
| 프로모션이 랭킹을 오염 | "진짜 인기작이 뭔지 모르겠다" |
| 추천이 취향과 불일치 | 광고성 추천과 실제 추천이 구분되지 않음 |

### 1.2 뷰어

| 문제 | 해당 플랫폼 |
|---|---|
| 스크롤 모드에서 페이지 경계 전환이 거슬림 | 공통 |
| 폰트·간격 등 기본 커스터마이징 부재 | 카카오페이지 |
| TTS 문장 사이 침묵이 과도하게 길어 어색함 | 공통 |

### 1.3 광고 — 가장 강한 거부 신호

**가상캐스팅(배우 연기) 광고에 대한 거부감이 압도적이다.**

| 독자 발언 | 읽히는 것 |
|---|---|
| "원작 캐릭터랑 이미지가 안 맞음" | 이미 머릿속에 캐스팅이 끝나 있다 |
| "몰입이 깨진다" | 외부 이미지가 독서 경험을 침범한다 |
| "코스프레 같고 거부감 듦" | 재현의 어설픔이 아니라 재현 자체를 거부 |
| "2D·3D는 아예 다른 세상인 느낌" | 매체가 바뀌면 다른 작품으로 인식 |

| 그 밖 | |
|---|---|
| 읽는 도중 광고 노출 | 즉각적 불만 |

> 이 항목은 슥의 핵심 가정과 정면으로 충돌한다.
> 분석은 [잠재 사용자 리서치 §3](잠재%20사용자%20리서치.md) 참고.

### 1.4 서재 · 결제

| 문제 | 해당 플랫폼 |
|---|---|
| 연재작 새 회차 구매 시 서재 분류가 초기화됨 | 공통 |
| 앱 내 결제 불가 — 웹으로 이동해야 함 | 리디 |
| 이용권 시스템 폐지로 독자 반발 | 네이버 시리즈 |

### 1.5 기타

| 문제 | 해당 플랫폼 |
|---|---|
| PC 버전 사실상 방치 | 카카오페이지 |
| 앱 무거움 · 크래시 · 무한 로딩 | 공통 |
| 표지를 크게 볼 수 없음 | 리디 |

## 2. 긍정 반응

| 기능 | 평가 | 비고 |
|---|---|---|
| **기다리면 무료** | 가장 성공한 과금 모델로 꼽힘 | 유입 효과 압도적 |
| **별점 · 댓글** | 작품 선택 기준으로 신뢰도 높음 | 8.5 이상이면 볼 만하다는 암묵적 기준 형성 |
| **이모티콘 댓글** | 호평 | 카카오톡 연동으로 감정 표현이 다채로움 |
| **TTS** | 수요 높음 | 이동 중 · 집안일 중 소비 패턴에 부합 |
| **연관 작품 추천** | 호평 | 작품 상세 하단 배치 |
| **다크모드 뷰어** | 사실상 필수로 인식 | 야간 독서 비중이 높음 |
