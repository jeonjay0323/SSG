# 작가 인터뷰

> 대상: 현역 웹소설 작가
> 방식: 비구조화 심층 인터뷰
> 기록일: 2026-09-17 (인터뷰는 그 이전에 진행)

이 서비스의 **출발점이 된 인터뷰**다. 기능 목록을 먼저 정해두고 검증한 것이 아니라,
작가가 실제로 한 말에서 방향이 뒤집혔다.

---

## 1. 그대로 옮긴 두 마디

> **"AI로 글 쓰는 건 돕는다는데, 사진·영상은 생성해본 적 없어요.
> 어렵고 필요한가 싶고."**

> **"제 작품 드라마화는 꿈같은 얘기. 일단 인기가 많아야 하고…
> 포스타입이랑 X에서 열심히 홍보 중이에요."**

---

## 2. 이 두 마디에서 읽은 것

### 2.1 타깃은 AI 사용자가 아니라 **AI 비사용자**다

"어렵고 필요한가 싶고" — 거부가 아니라 **무관심**이다. 설득 대상이 아니라 설계 대상이다.

| | |
|---|---|
| 하면 안 되는 것 | 제품을 "AI 영상 제작 툴"로 파는 것 |
| 해야 하는 것 | 프롬프트 0개 · 원고만 붙여넣기 · **결과물만** 보여주기 |

'AI'라는 단어를 전면에 세우는 순간 이 사람은 자기 얘기가 아니라고 판단한다.
기술은 뒤에 숨고 결과만 앞에 선다.

### 2.2 진짜 Job-to-be-done은 "감독 되기"가 아니라 **"내 작품 알리기"**다

작가는 이미 X와 포스타입에서 **홍보 노동을 하고 있다.** 시간을 쓰고 있다.
새로운 욕구를 만들 필요가 없다 — 이미 있는 노동을 더 잘하게 하면 된다.

우리가 "당신을 감독으로 만들어드립니다"라고 말하면 새 일거리를 주는 것이고,
"지금 하는 홍보를 영상으로 무장시켜드립니다"라고 말하면 있는 일을 덜어주는 것이다.

### 2.3 핵심 페인은 **닭-달걀 고리**다

```
인기가 있어야  →  영상화된다
영상화돼야     →  인기가 생긴다
```

"일단 인기가 많아야 하고"는 체념이다. 작가는 이 고리를 스스로 못 끊는다.

**슥의 개입 지점이 정확히 여기다.** 인기가 없어도 **먼저** 영상화하고,
그 영상으로 인기를 만들어 고리를 끊는다. 순서를 뒤집는 것이 제품의 본질이다.

---

## 3. 포지셔닝 전환

| | 문구 | 판정 |
|---|---|---|
| 이전 | "작가가 감독이 되는 AI 스튜디오" | ❌ 어렵고 불필요하게 들림 |
| 이후 | **"이미 하는 홍보를 영상으로 무장"** | ✅ 이미 겪는 문제에 붙음 |

**진입 쐐기는 풀 에피소드가 아니라 X에 올릴 30초 트레일러다.**
완성된 웹드라마 한 편은 작가에게 너무 먼 약속이다. 내일 당장 트위터에 올릴
30초짜리는 오늘의 홍보 노동에 바로 꽂힌다.

슬로건 후보: **"쓰면, 드라마가 된다"** / "이제, 소설을 봅니다"

---

## 4. 이 인터뷰의 한계 — 반드시 채워야 할 것

이 문서는 **소수 표본의 심층 인터뷰**다. 방향을 잡는 데는 충분했지만
근거로 쓰기에는 부족하다. 아래는 아직 답을 못 얻은 질문이다.

- [ ] 표본 확대 — 최소 5~7명 (연재 중 / 완결 / 데뷔 전 각 구간)
- [ ] 홍보에 실제로 **주당 몇 시간**을 쓰는가
- [ ] 홍보 채널별 체감 효과 (X · 포스타입 · 커뮤니티) 순위
- [ ] 트레일러가 나왔을 때 **실제로 올릴 것인가** — 말이 아니라 행동 의향
- [ ] 캐릭터가 내 상상과 다르게 생겼을 때의 수용 범위
- [ ] 지불 의사 — 무료라면 쓰는가, 얼마부터 안 쓰는가
- [ ] 소속 CP사가 있는 작가의 경우 **2차 창작물 권리** 문제
