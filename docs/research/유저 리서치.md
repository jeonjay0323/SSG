# 유저 리서치

> 출처: [작가 인터뷰](작가%20인터뷰.md) · [시장 조사](시장%20조사.md) ·
> [기존 웹소설 플랫폼 유저 반응](기존%20웹소설%20플랫폼%20유저%20반응.md)

슥에는 사용자가 둘이다. **영상을 만드는 작가**와 **영상을 보는 독자**.
둘의 이해가 한 곳에서 충돌하는데, 그 지점이 이 제품의 최대 리스크다.

---

## 1. 작가 — 만드는 쪽

### 1.1 페르소나

**"연재 3개월차, 조회수가 안 오른다"**

| | |
|---|---|
| 상황 | 연재 중 · 편당 수익 500만 원 미만 **(작가의 70.8%)** |
| 하고 있는 일 | X · 포스타입에서 직접 홍보 |
| AI 사용 경험 | 글쓰기 보조는 들어봤다. **이미지·영상은 만들어본 적 없다** |
| 영상화 인식 | *"꿈같은 얘기. 일단 인기가 많아야 하고…"* |

### 1.2 Job-to-be-done

> ❌ "내 소설을 영상으로 만들고 싶다"
> ✅ **"내 소설을 더 많은 사람이 읽게 하고 싶다"**

영상은 목적이 아니라 **홍보 수단**이다. 이 순서를 뒤집으면 제품이 틀어진다.

### 1.3 페인 — 닭-달걀

```
인기가 있어야 → 영상화된다      ↺  작가는 이 고리를 스스로 못 끊는다
영상화돼야   → 인기가 생긴다
```

### 1.4 설계 규칙

| 하지 말 것 | 할 것 |
|---|---|
| "AI 스튜디오"로 소개 | 결과물부터 보여주기 · AI라는 단어 숨기기 |
| 프롬프트 입력 요구 | 원고 붙여넣기 하나 |
| 풀 에피소드부터 제안 | **30초 트레일러**로 진입 |
| "감독이 되세요" | "지금 하는 홍보를 영상으로 무장" |

## 2. 독자 — 보는 쪽

### 2.1 이미 지갑을 연다

| | |
|---|---|
| 유료 결제 경험 | 79.0% |
| 1회 평균 결제액 | 8,032원 |

수요 부족 문제가 아니다.

### 2.2 검증된 선호

- **기다리면 무료** — 가장 성공한 과금 모델
- **별점·댓글** — 8.5 이상이면 볼 만하다는 암묵적 기준
- **TTS** — 이동 중·집안일 중 소비 패턴에 부합
- **다크모드** — 야간 독서 비중이 높아 사실상 필수

## 3. ⚠ 최대 리스크 — 두 사용자가 여기서 충돌한다

독자 조사에서 나온 가장 강한 부정 신호는 **가상캐스팅에 대한 거부감**이었다.

> *"원작 캐릭터랑 이미지가 안 맞음"*
> *"몰입이 깨진다"*
> *"코스프레 같고 거부감 듦"*
> *"2D·3D는 아예 다른 세상인 느낌"*

**이것은 슥의 핵심 가정을 정면으로 때린다.**
작가에게는 홍보 무기인 영상이, 독자에게는 **상상을 침범하는 물건**일 수 있다.

### 왜 거부하는가

독자는 읽으면서 **자기 머릿속에 이미 캐스팅을 끝냈다.**
외부에서 온 얼굴은 그 캐스팅을 덮어쓴다. 품질 문제가 아니라 **소유권 문제**다.

### 대응 가설 — 검증 필요

| 가설 | 근거 | 검증 방법 |
|---|---|---|
| **읽기 전에 보면 괜찮다** | 침범할 상상이 아직 없다 → 트레일러가 진입 쐐기인 이유와 맞물림 | 읽은 독자 / 안 읽은 독자 반응 비교 |
| **실사보다 애니·웹툰 풍이 안전하다** | *"2D·3D는 아예 다른 세상"* → 양식화가 거리를 만든다 | 매체별 A/B |
| **작가가 직접 만들면 정당성이 생긴다** | 플랫폼 광고가 아니라 원작자의 선택 | "작가가 만든" 표기 유무 비교 |
| **얼굴을 덜 보여주면 덜 부딪힌다** | 분위기·상황 중심 연출 | 얼굴 노출 비중별 반응 |

> 전시 파이프라인에서 얼굴 일관성에 공을 들인 것도 같은 문제의 다른 얼굴이다.
> 일관성이 깨지면 거부감이 더 커진다.

## 4. 종합

```
작가                          독자
"알려지고 싶다"                "내 상상을 지키고 싶다"
        └──────  슥  ──────────┘
     이 둘을 동시에 만족시켜야 한다
```

**설계 결론**

1. 진입은 **읽기 전** 지점 — 트레일러·PV. 상상이 형성되기 전에 만난다
2. 매체는 **양식화된 쪽**(애니메이션·웹툰 풍)을 기본으로. 실사는 신중히
3. **"작가가 직접 만든"** 이라는 맥락을 항상 붙인다
4. 독자용 뷰어에서는 영상을 **강제하지 않는다** — 토글로 둔다
