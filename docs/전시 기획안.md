# 전시 기획안
> **웹소설 플랫폼 ‘쓱’의 핵심 기능과 세계관을 오프라인으로 확장한 몰입형 전시**

본 전시는 단순한 서비스 홍보를 넘어, 관람객이 직접 소설 속 주인공으로 빙의하는 **'역할 수행(Role-playing)'** 경험을 통해 플랫폼의 AI 기술력과 콘텐츠의 몰입감을 동시에 체감하는 것을 목표로 합니다.

---

## 1. 전시 개요

### 1.1 전시 정의
플랫폼 '쓱'의 대표 IP와 AI 기술(인터랙티브 센서, 이미지 생성)을 결합한 **참여형 스토리텔링 전시**입니다.

### 1.2 전시 목적

| 목적 | 방법 |
| :--- | :--- |
| **브랜드 인지** | '빙의'라는 웹소설 특유의 문법을 오프라인 공간에 구현 |
| **기능 체감** | AI 이미지 생성·TTS 등 핵심 기능을 전시 동선 내 자연스럽게 배치 |
| **바이럴 확산** | 캐릭터 중심 포토존과 인터랙티브 요소로 SNS 공유 유도 |

### 1.3 핵심 컨셉

> **Possession(빙의) → Interaction(교감) → Experience(체험) → Share(확산)**

---

## 2. 전시 공간 및 레이어

| 레이어 | 명칭 | 주요 연출 | 핵심 가치 |
| :--- | :--- | :--- | :--- |
| **Identity** | 입구 및 메인 존 | 빙의 설정 안내, 북부대공 인터랙티브 영상 | 세계관 몰입 및 흥미 유발 |
| **Function** | 브랜드/서비스 존 | 기능 시각화 패널, 서비스 소개 영상(QR) | 플랫폼 기능 및 비전 전달 |
| **Product** | 체험 존 | 웹/앱 데모 디바이스, AI 기능 실연 | 실제 사용 경험 및 유저 확보 |
| **Memory** | 포토존 | 캐릭터 등신대, 테마 배경 연출 | 브랜드 애착 및 바이럴 |

## 3. 상세 구성 (Detailed Sections)

### 3.1 메인 콘텐츠: [북부대공이 나에게 집착한다]

| 요소 | 내용 |
| :--- | :--- |
| **빙의 연출** | "당신은 결말을 아는 유일한 존재입니다" 문구와 함께 조명 센서 가동 |
| **Interactive Media** | RFID·NFC 기반 영상. 관람객의 선택에 따라 캐릭터의 자세·대사가 변화 |

### 3.2 브랜드 아카이브: [Service Insight]

| 요소 | 내용 |
| :--- | :--- |
| **Visualizing Features** | AI 이미지 생성·TTS·스마트 에디터를 인포그래픽 벽보로 구성 |
| **Media Guide** | 유튜브 QR 배치 — 사용 가이드 및 브랜드 필름 시청 유도 |

### 3.3 프로덕트 데모: [Workstation]

| 요소 | 내용 |
| :--- | :--- |
| **Multi-Device Experience** | 태블릿(웹)·스마트폰(앱)을 각각 배치해 최적화된 UI 탐색 |
| **Feature Test** | 사전 세팅된 작품으로 AI 삽화 생성 과정과 TTS를 직접 체험 |

### 3.4 포토 스테이션: [Fan Meeting]

| 요소 | 내용 |
| :--- | :--- |
| **Character Standee** | 북부대공 실물 등신대. 관람객과 시선이 맞는 구도로 설계 |
| **UGC Trigger** | 전시 한정 굿즈 및 SNS 이벤트로 현장 경험의 디지털 확산 유도 |

## 4. 관람객 흐름 (Visitor Flow)

| Step | 단계 | 내용 |
| :---: | :--- | :--- |
| 1 | **Entrance** | 세계관 진입 통로 통과, 소설 속 인물로 역할 부여(빙의) |
| 2 | **Engagement** | 북부대공과의 인터랙션으로 몰입감 고조 |
| 3 | **Learning** | 체험한 감동이 어떤 기술에서 비롯됐는지 서비스 기능 확인 |
| 4 | **Conversion** | 준비된 디바이스로 실제 서비스 조작 — 가입·사용 장벽 완화 |
| 5 | **Closing** | 포토존 촬영 및 SNS 업로드로 경험 공유 |

| **Materials** | 폼보드 실사 출력(등신대), 고투명 아크릴 패널(세계관 설명) |

## 6. 기대 효과 및 전략 요약

본 전시는 **"기술이 만드는 이야기의 실재감"**을 오프라인으로 증명합니다. 단순한 기능 나열이 아닌, 웹소설의 가장 강력한 소구점인 **'관계성'**과 **'몰입'**을 인터랙티브 기술로 구현함으로써 잠재 고객들에게 플랫폼 '쓱'에 대한 강력한 브랜드 충성도를 심어줄 것입니다.
