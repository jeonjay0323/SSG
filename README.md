## 풀어야 했던 문제

AI 영상 모델로 **이어지는 이야기**를 만들려면 두 가지가 필요하다.
같은 인물이 유지되어야 하고, 장면이 매끄럽게 이어져야 한다. 둘 다 기본으로는 안 된다.

### 제약 — 시작 프레임과 인물 레퍼런스를 함께 못 준다

```
Image and reference images cannot be both set
```

Veo 3.1 은 이 둘을 동시에 받지 않는다. 게다가 reference-to-video 는
standard 티어 + 8초에서만 동작한다. 앞 장면에서 이어가려면 시작 프레임이 필수인데,
그러면 **인물 레퍼런스를 넣을 자리가 없다.** 세대를 거듭할수록 얼굴이 밀린다.

### 해결 1 — 리스테이징

인물 고정을 영상 모델이 아니라 **이미지 모델 단계**로 옮겼다.

```
앞 클립의 마지막 프레임  +  배우 레퍼런스
            │  gemini-2.5-flash-image
            ▼
  얼굴이 교정되고 앵글이 바뀐 '다음 컷의 첫 프레임'
            │
            ▼
         Veo 3.1
```

얼굴 교정과 앵글 변경은 **주기가 다르다.** 교정은 매 씬, 앵글은 `restageEvery` 주기.
둘을 한 스위치로 묶으면 앵글을 유지하는 씬에 레퍼런스가 안 들어가 얼굴이 밀린다.

### 해결 2 — 체이닝 + 트리밍

다음 씬의 시작점을 클립 중간에서 뽑으면, 클립은 끝까지 재생되는데
다음 씬은 그 앞 상태에서 시작한다. **되감기처럼 보인다.**

시드 지점에서 클립을 잘라 `클립의 끝 = 다음 씬의 시작`을 맞췄다.

### 해결 3 — 문장 해석

참여자 입력을 그대로 넘기면 깨진다.

| 입력 | 그대로 넘기면 | 해석 후 |
|---|---|---|
| "안녕" | 화면에 **글자로 렌더된다** | 세계 안의 작은 사건으로 치환 |
| "지하철이 왔다" (판타지 숲) | 세계 밖 물체가 등장 | 의도를 유지한 채 세계 안 사물로 |

자막에는 원문을 그대로 띄운다. 해석은 뒤에 숨고 소유감은 지킨다.

### 해결 4 — 대기 시간 숨기기

생성은 기다림이다. 현장에서 45초는 이탈 시간이다.

| 장치 | 효과 |
|---|---|
| 접수 즉시 문장을 큰 화면에 노출 | 영상은 45초 뒤지만 **내 흔적은 1초 만에** |
| 리스테이징된 첫 프레임 선공개 | 빈 대기가 예고편이 된다 |
| 접수 창 동안 미리 리스테이징 | 72초 → **47초** |
| 트랙 3개 독립 구동 | 앞사람 라운드를 기다리지 않는다 |

## 무인으로 며칠을 버텨야 한다

| 장치 | 동작 |
|---|---|
| 입력 필터 | 자모 분리·기호 삽입 우회까지 정규화해서 접수 시점에 차단 |
| canon 스냅샷 | 라운드 확정마다 저장. 서버가 죽어도 이야기가 이어진다 |
| 예산 상한 | 건수·금액 양쪽. 넘으면 조용히 드라이런으로 내려간다 |
| 단계별 폴백 | 리스테이징 실패 → 원본 프레임 / 생성 실패 → 정지화면, 투표는 진행 |

세 트랙이 동시에 끝날 때 서버가 멈추는 **데드락**이 있었다.
드라이버는 트랙락→엔진락, HTTP 는 엔진락→트랙락 순서였다. 락 순서를 하나로 고정해 풀었다.

## 왜 이 서비스인가

방향은 기능 목록이 아니라 **작가 인터뷰**에서 나왔다.

> "AI로 글 쓰는 건 돕는다는데, 사진·영상은 생성해본 적 없어요. 어렵고 필요한가 싶고."
>
> "제 작품 드라마화는 꿈같은 얘기. 일단 인기가 많아야 하고…
> 포스타입이랑 X에서 열심히 홍보 중이에요."

여기서 두 가지가 뒤집혔다.

| | 이전 | 이후 |
|---|---|---|
| 타깃 | AI를 쓰고 싶은 창작자 | **AI를 안 써본 작가** |
| 소구 | "작가가 감독이 되는 AI 스튜디오" | **"이미 하는 홍보를 영상으로 무장"** |
| 진입점 | 풀 에피소드 | **X에 올릴 30초 트레일러** |

핵심 페인은 **닭-달걀**이다. 인기가 있어야 영상화되고, 영상화돼야 인기가 생긴다.
슥은 순서를 뒤집는다 — 인기 없어도 먼저 영상화하고, 그걸로 인기를 만든다.

숫자가 이 자리를 가리킨다.

| | |
|---|---:|
| 웹소설 시장 | 1조 3,500억 원 |
| 그런데 작가의 70.8% | 편당 500만 원 미만 |
| 영상화되는 작가 | 사실상 상위 1% |
| 숏폼 드라마 시장 | 17조 → 38조 (2030 전망) |
